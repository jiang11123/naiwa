# 🐸 奶蛙骑行 (Naiwa Bicycle) - 矢量 SVG 2D 动效网页

> 纯矢量 SVG + 物理反向运动学 (IK) 解算的「奶蛙骑自行车」交互式 2D 动效网页。

## 🌟 核心特色

1. **奶蛙造型极致复刻**：
   - 呆萌圆润的黄色蛙形躯体与流畅曲线；
   - 侧生大眼眶，内嵌深绿色层次渐变蛙眼大虹膜、纯黑瞳孔与高光光斑，搭配安详淡定的“一”字型小唇缝；
   - 经典西装正装：挺拔纯白衬衫、缎面纯黑小领带（迎风飘逸）、驼米色三纽扣马甲、深藏青定制小西服外套以及**左胸还原的微缩黑板教师工牌**；
   - 暗橄榄绿青蛙蹼手牢牢抓握车把，脚踩踏板。

2. **严谨的机械动力学与运动学 (IK 解算)**：
   - **双骨节解析反向动力学 (Inverse Kinematics)**：奶蛙双腿并非生硬的固定贴图，而是依据五通轴心（Bottom Bracket）与脚踏板曲柄回旋角度，实时解算髋关节、膝关节与踝关节坐标。膝盖始终自然向前弯曲，双脚 100% 紧贴脚踏做平滑椭圆循环运动；
   - **车身与角色微动作共振**：身体伴随踩踏节奏产生自然的 Q 弹上下起伏与微俯仰倾角；领带迎风随速摆动；随机触发呆萌眨眼；
   - **辐条与胎纹精确同步**：车轮自转速度与公路地面标线滚动严格成正比。

3. **多层次景深环境**：
   - 动态道路中心线视差滚动；
   - 中景路边树木与远景连绵山丘；
   - 高空飘浮白云、轮胎后扬起微尘粒子与破风速度线。

4. **丰富好玩的交互体验**：
   - ⏯ **暂停 / 骑行切换**；
   - ⚡ **踩踏速度无级调节**（0.3x 悠闲散步 ~ 3.0x 狂飙）；
   - 🚀 **狂飙冲刺按钮**（瞬间爆发并触发口播台词）；
   - 🔔 **仿真复古车铃**：Web Audio API 纯代码合成金属双音“叮铃铃~”，伴随车铃摇晃与 SVG 声波涟漪扩散；
   - 🌙 **昼夜模式切换**：支持阳光明媚的白天与静谧深邃的夜骑巡航（夜间自动点缀漫天繁星、点亮车头强光照射光锥）；
   - 💬 **随机对话气泡**：点击奶蛙身体即可弹出趣味教学金句台词。

## 🚀 快速启动

本项目为纯前端单文件工程，无需配置任何 Node 或打包编译环境：

1. 克隆本仓库到本地：
   ```bash
   git clone https://github.com/jiang11123/naiwa.git
   ```
2. 直接双击打开 `index.html` 或 `naiwa_bicycle.html` 即可在任意现代浏览器中流畅运行。

## 🛠️ 技术栈

- **渲染引擎**：原生 Inline SVG (Scalable Vector Graphics)
- **动效计算**：原生 JavaScript (`requestAnimationFrame` + 2D IK 数学解析解)
- **音效系统**：Web Audio API (双正弦振荡器与指数包络衰减)
- **样式表现**：CSS3 Variables / Flexbox / Backdrop Filter
